# EXP006 — least Goldbach prime profile

EXP006 derives the first (smallest) prime summand for each even `n` in the frozen EXP005 pair file. It is an analysis of validated raw data, not a new proof attempt.

The largest observed least prime through `100000` is `293`, at `63274 = 293 + 62981`. The result is computational and bounded; prior literature already studies minimal Goldbach partitions, so novelty is not claimed.
